# MY LOCK Shape Lab

Shape Lab is the lightweight development surface for designing and reviewing lock shapes without opening the full app.

## Source-of-truth rule

A shape must never have a separate "mockup implementation" and "app implementation".

- `ShapeBlueprint` is the geometry source of truth for illustrated shapes.
- `LockTokenPainter` is the renderer used by both the production app and Shape Lab.
- Preview PNGs are generated by Flutter from that same painter at 58 logical pixels and DPR 4.
- A screenshot or manually redrawn SVG is reference material only. It is not an app asset unless its coordinates are converted into the blueprint.

## Adding an illustrated shape

1. Add the new `ShapeKind`.
2. Add one `ShapeBlueprint` entry in `lib/lock_engine/shape_geometry.dart`.
3. Keep design coordinates in the 100 x 100 viewBox.
4. Use `ShapeTracePart` for body / tail / fins / accent regions.
5. Push to `feat/shape-lab`.
6. Review the generated `my-lock-shape-previews` artifact and the standalone Shape Lab.
7. Only merge an approved geometry into the release branch.

## Review sizes

- Exact: 58 x 58 logical px.
- Chat/review artifact: the same 58 x 58 render captured at DPR 4 (232 x 232 physical px).
- Large Shape Lab view: the exact 58 x 58 result scaled up. It is not re-rendered with different geometry.

## Draft controls

Shape Lab's Draft controls apply a temporary transform around the production painter.

They are for finding the desired scale / width / height / offset quickly. Draft values do not change production geometry until explicitly transferred into the blueprint.

## Geometry conventions

- Design viewBox: 100 x 100.
- Default design center: (50, 50).
- `referenceRadius` controls optical scale relative to the normal token radius.
- Keep small details only if they remain readable at 58 px.
- `accent` parts are excluded from the combined hit silhouette; structural parts are unioned.
