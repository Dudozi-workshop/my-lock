MyLock 개인정보처리방침

시행일: 2026년 9월 22일

Dudozi Workshop(이하 “개발자”)은 MyLock(이하 “앱”) 이용자의 개인정보와 기기 정보를 중요하게 생각합니다. 이 정책은 앱이 어떤 정보에 접근하고 어떻게 사용하는지 설명합니다.

1. 수집·저장하는 정보

MyLock은 회원가입, 로그인, 광고, 분석 SDK 또는 클라우드 동기화를 제공하지 않습니다. 앱의 잠금 기능을 위해 다음 정보가 이용자의 기기에만 저장될 수 있습니다.

  • 사용자가 선택한 보호 앱의 패키지 식별자
  • 잠금 설정, 도형·색상 조합, 잠금 정책, 배경·효과 설정
  • 잠금 패턴 검증값과 보조 PIN 검증값
  • 보호 기능의 마지막 실행 상태와 재부팅 후 복구에 필요한 상태값

2. 기기 권한 및 사용 목적

  • 앱 사용 정보 접근: 보호 앱이 현재 화면에 열렸는지 기기 안에서 확인하고 잠금 화면을 표시하기 위해 사용합니다.
  • 다른 앱 위에 표시: 보호 앱 위에 MyLock 잠금 화면을 표시하기 위해 사용합니다. MyLock은 다른 앱의 화면 내용, 메시지, 입력 내용을 읽거나 저장하지 않습니다.
  • 알림·포그라운드 서비스: 보호 기능이 실행 중임을 표시하고 백그라운드 보호 감시가 중단되지 않도록 사용합니다.
  • 부팅 완료: 사용자가 설정한 보호 기능을 기기 재부팅 후 복구하기 위해 사용합니다.

3. 정보의 외부 전송 및 공유

MyLock은 위 정보를 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 정보를 판매하거나 광고·분석 목적으로 사용하지 않습니다.

4. 보관 및 삭제

정보는 앱의 내부 저장공간에 보관됩니다. 이용자는 앱 설정을 초기화하거나 Android 설정에서 앱 데이터를 삭제하여 저장된 정보를 삭제할 수 있습니다. 앱을 삭제하면 앱 내부에 저장된 정보도 함께 삭제됩니다. MyLock은 별도 계정을 제공하지 않으므로 계정 삭제 절차는 필요하지 않습니다.

5. 정보 보호

저장 정보는 Android 앱 샌드박스와 운영체제의 접근 제어를 통해 보호됩니다. 개발자는 필요한 기능 범위 안에서만 정보를 사용하며, 앱의 데이터 처리 방식이 변경되면 이 정책을 갱신합니다.
