## Purpose
MY LOCK visual assets must feel like one authored world even when the subject changes. The identity comes from **how things are drawn**, not from forcing the same colors or motifs onto every asset.

This standard applies above individual Drops and covers Shape, Background, Environment Object, Theme Illustration, and representative art.

## Visual Essence
- Soft Illustrated 2D / 2.5D
- rounded, organic silhouette language
- large color masses before micro-detail
- shallow, soft structural shading
- no black hard outline
- clear but soft illustrated contour
- calm, warm, slightly dreamy emotional tone
- readable at small runtime size
- base art should not depend on glow, glassiness, neon, or heavy highlight effects

## Visual DNA — 7 axes

| Axis | MY LOCK rule |
| --- | --- |
| Shape Language | Rounded and organic. Avoid unnecessary sharpness or rigid geometry. |
| Proportion | Stable, slightly compact proportions. Recognition and balance over exaggerated cuteness. |
| Color Blocking | Large color areas first. Avoid unnecessary rainbow-like internal fragmentation. |
| Shading | Soft and shallow. Used to explain form, depth, and overlap rather than show off lighting. |
| Edge Language | No black hard outline. Contours should stay clear while blending naturally into local color. |
| Detail Rhythm | Large mass → structural detail → minimal decoration. Details visible only at extreme zoom are low priority. |
| Emotional Tone | Quiet, warm, calm, slightly dreamy; not overly childish, neon, or spectacle-driven. |

## Style Anchor

### Primary Anchor — Sea Turtle v3
Sea Turtle v3 is the current reference point for the most stable MY LOCK illustration language.

Extract from it:
- curve character
- color-mass size
- shading depth
- edge softness
- detail density
- restrained dimensionality

Do **not** copy the turtle's literal colors or patterns into other assets.

### Calibration Set
- Sea Turtle v3 — Style Anchor
- Dolphin — same-Drop biological comparison
- Jellyfish — first active Style Calibration target
- Shallow Clear Sea Planning Visual Master v1 — Background Composition Anchor

## Shape Rules
- silhouette and large color masses must read first
- internal detail must explain structure
- facial features and decoration remain minimal unless essential
- highlights stay low-intensity and structural
- glow, strong transparency, neon, and glassy rendering are not the base identity
- runtime-size readability is mandatory

## Background / Environment Rules
Backgrounds do not use a separate art style.

Rocks, coral, seaweed, sand, clouds, stars, trees, and other environment objects must share:
- the same organic shape language
- comparable color-mass scale
- comparable shading depth
- comparable edge softness
- comparable detail density

Drops may vary through palette, composition, and subject selection, but not by changing the core drawing language.

## Base Illustration vs Effect
The following are **not** part of the core drawing style and are handled later as Effect treatment when needed:
- strong highlight / specular
- glassy look
- glow / bloom
- surface refraction
- caustic
- moving light
- bubbles / particles
- aurora / moving water-light
- sparkle

Base illustration must still look complete and recognizably MY LOCK with these effects disabled.

### Material planning status
The previous Material product / Material compatibility plan is retired. References to Glossy / Jelly / Glass / Matte / Metal / Hologram in legacy documents are not active production gates. Do not restore or infer Material work from legacy text.

## Prohibited Directions
- black-outline cartoon rendering
- strong cel shading
- photorealistic 3D rendering
- excessive glass / jelly / plastic gloss
- neon-led visual identity
- excessive multicolor gradients inside one object
- micro-texture overload
- backgrounds rendered in a separate highly painterly style
- asset-specific art styles that break cross-asset consistency
- baking heavy Effect treatment into the base illustration as the source of identity

## Cross-Asset Consistency QA
Every new visual asset must be compared side-by-side with at least one established anchor.

Evaluate:
1. Silhouette
2. Color Mass
3. Shading
4. Detail Density
5. Edge Treatment
6. Emotional Tone
7. World Fit

Result states:
- PASS
- CALIBRATE
- REJECT

## Current Calibration

- reduce pink/purple internal mixing
- reduce strong white highlights
- remove glow-like brightness
- reduce tentacle-by-tentacle color scatter
- prioritize large Bell / tentacle color masses
- bring edge clarity to Sea Turtle level

- open central play field
- environmental density concentrated lower-left
- approved palette family
- approved object density

Only cross-check visual language: shape construction, color blocking, shading depth, edge treatment, and detail density.
