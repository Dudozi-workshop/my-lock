# MY LOCK Visual DNA v2 — Soft Storybook Character

Status: Active Working Standard / Candidate / Not Locked  
Date: 2026-10-05

## Core Direction
MY LOCK Base Art is 2D character illustration first. 2.5D treatment is limited to shallow structural depth used only to explain form and overlap.

Target impression:
- quiet, warm storybook characters
- rounded organic silhouettes
- large color masses before detail
- shallow, soft shading
- minimal face system
- illustrated character drawing over realistic or 3D-rendered form
- cute without becoming overly childish

## Drawing Language

### Shape Language
- simplify subjects into immediately recognizable character forms
- prefer rounded stable curves over sharp or rigid geometry
- silhouette and large-mass rhythm must read before detail

### Proportion
- slightly compact, soft proportions are allowed
- avoid exaggerated mascot proportions as the default
- character identity should come from curve language, silhouette, and minimal face more than extreme deformation

### Color Blocking
- prioritize 2–3 large color masses per character
- think in Base / Light Structural Plane / Dark Structural Plane
- avoid unnecessary multicolor fragmentation and rainbow-like gradients

### Shading
- use only to explain form, overlap, and front/back relationship
- broad, soft, and shallow
- no deep AO, strong specular, realistic reflection, or photorealistic volume in Base Art

### Edge Language
- no black hard outline
- use clear colored illustrated contours that remain legible while blending with local color
- clear like a sticker, but not a rigid vector cutout

## Minimal Face System
Minimal face is allowed as a common MY LOCK character-language tool.

Default:
- eyes: small dot or short oval
- mouth: short simple curve
- blush: optional, low contrast
- no default eyebrows, teeth, wide-open mouth, or exaggerated emotional acting
- face must not visually overpower silhouette or color identity
- place the face in a structurally stable area

Minimal face is not automatically applied to backgrounds or environmental objects.

## Detail & Texture
- detail order: Large Mass → Structural Detail → Minimal Decoration
- de-prioritize tiny patterns, micro sparkle, and small gloss accents in Base Art
- watercolor or pencil influence may appear only as very subtle hand-drawn softness
- do not create micro texture that collapses at runtime size

## Base Art vs Effect
The following are downstream Effect treatment, not core drawing identity:
- strong highlight / specular
- glassy / jelly / plastic gloss
- glow / bloom
- refraction / caustic
- moving light
- bubble / particle
- sparkle
- aurora / animated water-light

Base art must remain complete and recognizably MY LOCK with these disabled.

## Prohibited Directions
- realistic biological illustration
- photorealistic / realistic 3D-render look
- deep AO and strong volumetric lighting
- glass / jelly / plastic gloss as core identity
- black-outline cartoon rendering
- strong cel shading
- neon-led identity
- exaggerated facial acting
- overly childish mascot proportions
- asset-specific art styles
- micro-texture overload
